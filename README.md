# Учёт медицинских карт пациентов (Python + SQLite)

Учебное консольное приложение для 1 курса вуза.  
Реализовано на стандартном **Python 3** и встроенной базе данных **SQLite** без сторонних библиотек и сложных фреймворков.

## Структура репозитория

```text
medical-cards-sqlite/
├── src/
│   ├── main.py          # Консольное меню, ввод и валидация данных
│   └── database.py      # Работа с SQLite и CRUD-запросы
├── .gitignore           # Исключения для Git (__pycache__, *.db, .idea)
├── requirements.txt     # Зависимости проекта (только стандартная библиотека)
├── LICENSE              # Лицензия MIT
└── README.md            # Документация проекта
```

Файл базы данных `medical_cards.db` создаётся автоматически в корне проекта при первом запуске и исключён из Git через `.gitignore`.

## Требования и запуск

Сторонние пакеты устанавливать не нужно (`requirements.txt` не содержит внешних зависимостей).  
Достаточно установленного **Python 3.8+**.

1. Клонируйте репозиторий или распакуйте архив:

```bash
git clone https://github.com/<ваш-логин>/medical-cards-sqlite.git
cd medical-cards-sqlite
```

2. Запустите консольное приложение:

```bash
python src/main.py
```

*(На macOS или Linux может понадобиться команда `python3 src/main.py`.)*

## Возможности консольного меню

1. **Показать все медицинские карты** — выводит полный список пациентов из таблицы `patients`.
2. **Добавить новую медицинскую карту** — пошаговый ввод с проверкой формата даты (`ДД.ММ.ГГГГ`), длины полиса ОМС (16 цифр) и уникальности номера карты.
3. **Найти пациента** — поиск без учёта регистра по ФИО, номеру карты, полису или диагнозу.
4. **Редактировать запись** — обновление диагноза или контактного телефона по `ID`.
5. **Удалить запись** — удаление медицинской карты по `ID` с обязательным подтверждением.

## Схема таблицы `patients`

| Поле | Тип SQLite | Описание |
| :--- | :--- | :--- |
| `id` | `INTEGER PRIMARY KEY AUTOINCREMENT` | Уникальный номер записи |
| `card_number` | `TEXT UNIQUE NOT NULL` | Номер медицинской карты |
| `full_name` | `TEXT NOT NULL` | ФИО пациента |
| `birth_date` | `TEXT NOT NULL` | Дата рождения (`ДД.ММ.ГГГГ`) |
| `policy_number` | `TEXT UNIQUE NOT NULL` | Полис ОМС (16 цифр) |
| `diagnosis` | `TEXT NOT NULL` | Диагноз / причина обращения |
| `phone` | `TEXT` | Контактный телефон |
| `created_at` | `TEXT NOT NULL` | Дата и время создания карты |
